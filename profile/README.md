## What is Fold?

**Fold** is a modular document processing toolkit designed to turn unstructured information into structured data - and structured data back into documents.

The project is built as a collection of independent components that can be combined into document workflows.

## Building blocks

|     | Module              | Purpose                                                      |
| --- | ------------------- | ------------------------------------------------------------ |
| 📄  | **Document → Data** | Extract structured data from PDF, images and other documents |
| 🏗️ | **Data → Document** | Generate documents from structured data                      |
| ✍️  | **Text → Data**     | Convert free-form text into structured information           |
| 🎙️ | **Speech → Text**   | Transcribe audio into usable text                            |
| 🔍  | **Validation**      | Validate extracted or generated information                  |
| 👁️ | **Human Review**    | Review and correct uncertain results                         |
| 🔄  | **Transformations** | Convert information between schemas and formats              |
| 🔌  | **Integrations**    | Send validated data to APIs, webhooks and external systems   |

---

## Philosophy

Fold is designed around a few principles:

**Modular** - each capability can evolve independently.

**Composable** - processing blocks can be assembled into different workflows.

**Provider-independent** - infrastructure, parsers, AI providers and output systems remain replaceable.

**Human-in-the-loop** - automated processing can escalate uncertain results for review.

**Structured by default** - raw information becomes predictable, validated data.
